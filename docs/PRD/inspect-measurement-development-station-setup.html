01 / CURRENT SETUP ASSESSMENT

Setup saat ini: cukup untuk Stage 0

Masih berguna untuk
  • Menguji capture → calibration → process → evaluate.
  • Mengembangkan edge merge, line fit, contour, dan overlay.
  • Mengumpulkan raw image dan negative cases.
Belum boleh digunakan untuk
  • Klaim akurasi produksi.
  • PASS/FAIL final berdasarkan toleransi drawing.
  • Menyimpan Station Preset sebagai calibrated station.

Risiko yang terlihat

  • HVS berlapis, memiliki sambungan, marking, dan potensi tidak rata.
  • Tepi kertas dapat terdeteksi sebagai edge palsu.
  • Mount, pan/tilt, tinggi camera, dan tarikan kabel mudah berubah.
  • Cahaya window menghasilkan shadow dan exposure yang berubah.
  • Autofocus dapat mengubah repeatability antar-capture.
  • Tidak ada independent reference dan ground truth terukur.

Perbaikan langsung tanpa membeli alat

  • Gunakan satu lembar HVS utuh dalam seluruh FOV.
  • Rekatkan ke permukaan keras dan datar.
  • Jauhkan sambungan, tulisan, dan tepi meja dari ROI.
  • Pusatkan komponen pada optical axis.
  • Kunci mount dan beri strain relief pada kabel.
  • Tutup cahaya window; pertahankan lampu yang sama.
  • Tunggu autofocus stabil sebelum capture.
  • Ambil 10 capture ulang tanpa mengubah setup.

Status hasil Stage 0: DEVELOPMENT / REVIEW. Komponen boleh dipakai sebagai reference hanya untuk debug; dimensi yang menjadi reference tidak boleh sekaligus divalidasi.

Aturan lintas tahap

  • Target face harus paralel terhadap measurement plane.
  • Working distance berarti camera → target surface, bukan hanya camera → desk.
  • Rotasi komponen menghasilkan view baru.
  • Preset hanya berlaku pada camera, resolution, FOV, focus/zoom, dan plane yang cocok.
  • Reference calibration harus independen dari dimensi yang dievaluasi.
  • Overlay Reference dan Garis Bantu default hidden setelah Process.
  • Raw detection tidak boleh menjadi nilai final tanpa geometry fitting.
  • Invalid calibration menghasilkan REVIEW, bukan PASS.
Multiscale wajib. Satu FOV tidak dapat sekaligus mencakup komponen 2100 mm dan fitur 1 mm secara presisi. Dengan lebar video 2560 px, cakupan 2100 mm hanya sekitar 1.22 px/mm sebelum margin. Gunakan preset/capture Global dan Detail terpisah.

Wajib

  • Rigid gantry/copy stand, tinggi adjustable dan dapat dikunci.
  • Camera mount rigid; pan/tilt tidak bergerak saat disentuh.
  • Flat base plate dengan cover matte hitam/putih interchangeable.
  • Dua LED bar/panel flicker-free, dimmable, dan diffuser.
  • Engineer square serta spirit/digital level.
  • Cable clamp/strain relief.
  • Digital caliper beresolusi 0.01 mm dengan accuracy terdokumentasi.

Tambahkan bila diperlukan

  • Low-profile clamp atau V-block untuk menjaga pose.
  • White diffuse backlight untuk silhouette/hole komponen kecil.
  • Light hood sederhana untuk memblokir ambient light.
  • Foot switch/capture button agar station tidak disentuh.
  • Polarizer bila sheet metal menghasilkan glare kuat.
Desk matte bukan alat ukur.
Grid atau marking hanya membantu alignment. Flat base plate dan independent reference tetap menjadi sumber geometry.

Equipment

  • Rigid matte ChArUco board, pattern sized for current FOV.
  • Independent reference plate/rectangle dengan X dan Y terukur.
  • Gauge block/riser untuk menyamakan reference plane dan target face.
  • Verification artifact berbeda dari artifact pembentuk preset.
  • Digital angle gauge/bevel protractor, rekomendasi accuracy ±0.1°.
  • Internal/external radius gauge.
  • Micrometer untuk ground truth ketebalan kecil.

Station Preset menyimpan

  • Camera ID dan resolution.
  • Global/Detail FOV.
  • Focus/zoom state.
  • Camera-to-desk dan target-plane height.
  • Effective working distance.
  • Camera matrix dan distortion coefficients.
  • Scale X/Y dan homography.
  • Valid range, verification result, date, operator.

Calibration workflow

  1. Intrinsic: capture ChArUco dari posisi dan sudut berbeda; simpan camera matrix, distortion, resolution, dan reprojection error.
  2. Planar: letakkan reference plate pada target plane; deteksi horizontal/vertical reference; hitung scale X/Y dan homography.
  3. Preset: simpan geometry hanya setelah camera, lighting, FOV, focus, working distance, dan plane dikunci.
  4. Verification: ukur artifact lain pada center dan empat area frame. Bias yang berubah berdasarkan posisi menunjukkan distortion/homography belum cukup.
Reference harus co-planar. Jika camera-to-desk 175 mm dan target face 13 mm di atas desk, effective working distance sekitar 162 mm. Scale desk tidak boleh langsung dipakai pada target face tersebut.

Checkpoint keluar Stage 2

  • Intrinsic calibration menyimpan reprojection error; target engineering awal ≤ 0.5 px.
  • Verification artifact diuji pada center dan empat area frame.
  • Bias dan repeatability setiap task ≤ 25% tolerance target.
  • Preset mismatch menghasilkan warning atau REVIEW.
  • Reference/Helper overlay dapat show/hide dan default hidden setelah Process.
  • Raw image, preset ID, calibration, result, dan evaluation masuk History/Audit.

06 / STAGE 3 — PILOT PRODUCTION & PROCUREMENT

Beli upgrade setelah bottleneck terbukti

PrioritasItemAlasan
BELI SEKARANGRigid gantry, flat base plate, dua diffuse light, level/square, cable clamp, caliperMenghilangkan sumber variasi terbesar tanpa mengganti camera.
SETELAH EDGE FITRigid ChArUco, reference plate X/Y, gauge blocks, verification artifact, angle/radius gaugesMembangun Station Preset dan evidence accuracy.
JIKA DIPERLUKANBacklight, polarizer, light enclosure, foot trigger, gantry encoderTambahkan hanya saat shadow, glare, ambient light, atau height drift terbukti.
PRODUCTIONIndustrial area-scan camera, fixed C-mount lens/telecentric detail lens, lighting controller, certified artifactDibutuhkan setelah capability target dan FOV produksi dikunci.

Pilot production menambahkan

  • Industrial camera dengan fixed optics dan hardware trigger.
  • Global dan Detail station/preset terpisah.
  • Gantry encoder atau distance sensor.
  • Lighting enclosure dan controlled driver/strobe.
  • Certified calibration artifacts dan calibration schedule.
  • Temperature record untuk komponen besar/metal.
  • Drawing/recipe dimension sebagai source of truth.
  • Measurement System Analysis / Gage R&R sebelum release.

Belum perlu dibeli

  • GPU atau AI model khusus measurement.
  • Robot/turntable otomatis.
  • 3D/depth camera.
  • Telecentric lens sebelum Detail FOV dan accuracy target diketahui.
  • Integrasi CMM sebelum workflow 2D repeatable.
Development camera boundary
Fantech C50 tetap dipakai untuk Stage 0–2 selama repeatability cukup. Autofocus, consumer optics, dan 2560 × 1440 menjadi batas capability yang harus dibuktikan, bukan diasumsikan.

Pilot release gate

  • Recipe/drawing mendefinisikan geometry, nominal, tolerance, pose, dan view.
  • Global/Detail capability memenuhi fitur minimum masing-masing.
  • Repeatability, bias, position dependency, dan operator variation terdokumentasi.
  • Invalid station state tidak dapat menghasilkan PASS.
  • Calibration expiry dan daily verification tersedia dalam audit trail.
  • Inspector training dan fallback Manual Reference telah diuji.

07 / DAILY CHECKLIST & REFERENCES

Checklist station harian

Sebelum shift

  • Lensa bersih dan privacy shutter terbuka.
  • Mount, gantry lock, serta cable clamp tidak longgar.
  • Resolution, FOV, focus, dan preset sesuai.
  • Lighting menyala dengan level yang ditetapkan.
  • Measurement plane bersih, datar, dan tidak rusak.
  • Verification gauge menghasilkan status Valid.

Setiap view

  • Nama view menjelaskan sisi/pose.
  • Target face menghadap camera dan paralel.
  • Objek tidak terpotong FOV.
  • Working distance sesuai preset.
  • Shadow/glare tidak menutup edge target.
  • Process dilakukan setelah capture dan calibration valid.

Setelah rotasi

  • Buat view baru; jangan menimpa raw image sebelumnya.
  • Periksa target-plane height yang baru.
  • Adjust gantry atau ganti preset bila working distance berubah.
  • Ulangi Manual Reference bila memakai fallback.

Jika verification gagal

  • Blokir PASS dan ubah status menjadi REVIEW.
  • Periksa mount, plane, lighting, focus, dan resolution.
  • Recalibrate atau gunakan Manual Reference.
  • Catat penyebab dan tindakan pada Audit.

Reference sources

  1. OpenCV 4.13 — Camera Calibration With OpenCV. Panduan camera matrix, distortion, supported calibration patterns, dan practical multi-frame calibration.
  2. OpenCV 4.13 — Create Calibration Pattern. Panduan ChArUco/chessboard, pattern size, flatness, matte surface, dan visibility.
  3. OpenCV 4.13 — LineSegmentDetector. Metadata line width, precision, dan NFA untuk refined candidate filtering.
  4. Fantech — Luminous C50 official specification. 2560 × 1440, 5 MP, autofocus, FoV 76°, 30 FPS @ 1440p.
